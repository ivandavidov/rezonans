# Резонанс в космоса — бележки за разработка

Самостоятелна игра: хоризонтален космически шутър в шест нива. Няма нищо общо с двигателя на „Резонанс“ —
папката `docs/space/` е цял проект и работи, където и да бъде преместена.

## Как се пуска
- Двоен клик на `index.html` (отваря се от `file://`) или произволен статичен сървър
  (`python3 -m http.server -d docs/space`); на сайта — `/space/`.
- Без сборка, без npm, без зависимости. Всичко е обикновени файлове.

## Правила, които пазят преносимостта
- **Само относителни пътища.** Нищо извън папката, нищо от мрежата.
- **Класически `<script src>`**, не ES модули, без `fetch`/`import` — при `file://` браузърите ги блокират.
- **Без файлове с картинки и звук**: спрайтовете се рисуват с Canvas 2D в атлас при старта (`js/art.js`),
  фоновете са шейдъри (`js/bg.js`), музиката и ефектите — синтезатор с WebAudio (`js/audio.js`).
  (Картинка от `file://` „замърсява“ WebGL, а `@font-face` към файл се блокира.)
- **Шрифтовете** са вградени като `data:` в `fonts/fonts.css` (Russo One, Exo 2; лицензи `fonts/OFL-*.txt`).
- **Manifest-ът** се закача само при http/https (иначе браузърът пише грешка в конзолата).
- **Логиката е детерминирана**: `js/core.js`, `js/sim/`, `js/levels/` ползват само семенния генератор `W.r`,
  никога `Math.random` — едно и също семе и вход дават едно и също състояние (на това стъпват проверките).
- **Записите**: един ключ `rezonans-space.v1` в `localStorage` (JSON с версия, всичко в try/catch).
  Произходът на сайта е общ с „Резонанс“, затова ключът е отделен.

## Устройство
| Файл | Какво прави |
|---|---|
| `index.html` | разметката на екраните и редът на скриптовете |
| `css/ui.css` | менюта, HUD, тъч слой, екрани; `--u` е мащабът на игралното поле |
| `js/core.js` | общото име `SPACE`, размери (1280×720), математика, семенен генератор, отпечатък |
| `js/sim/world.js` | светът: играч, оръжия, скала, предмети, сблъсъци, лъчи, вятър, стени, пулсар, сценарий, контролни точки |
| `js/sim/foes*.js` | враговете (`S.defFoe`) — по нива: `foes.js` 1, `foes2.js` 2–3, `foes3.js` 4–6 |
| `js/sim/bosses*.js` | босовете и частите им |
| `js/sim/progress.js` | имената на нивата, хангарът, медалите и бонусите |
| `js/sim/bot.js` | автопилотът (фонът на менютата и проверките) |
| `js/levels/l1…l6.js` | сценариите на нивата (`S.defLevel`) |
| `js/gl.js` | WebGL2: спрайтове на пакети, буфер на фона (обновява се на ивици), сияние, мъгла, финален пас |
| `js/art.js` | процедурните спрайтове → атлас 2048² (подредени по височина) |
| `js/bg.js` | фоновете на нивата (шейдъри), мъглата и светлината на пулсара |
| `js/fx.js` | частици, прах, трус, ударни вълни |
| `js/look.js` | как изглежда всичко от състоянието на логиката |
| `js/audio.js` | синтезаторът: ефекти по събития и музика (`TR`) със слоеве |
| `js/ui.js`, `js/main.js` | екраните, HUD, цикълът (логика 60 Hz + интерполация), настройки, качество |

Логиката говори навън само със събития в `W.ev` (`{k: 'boom', x, y, …}`) — от тях живеят звукът, ефектите и HUD-ът.

## Как се добавя…
- **враг**: `S.defFoe('име', { hp, r, score, cr, ch, boom, init, upd, die })` в `js/sim/foes*.js`;
  видът — клон в `foe()` в `js/look.js`, спрайтът — `add(...)` в `js/art.js`, цветът на взрива — `COL` в `js/fx.js`.
- **ниво**: `S.defLevel(n, { name, bg, music, boss, sspd, crv, brief, script })` в `js/levels/`; стъпките са
  `[секунди | 'clear' | 'cp', (A, W) => …]` с `A.line / v / one / many / boss / miniboss / banner / warn / wind / storm / walls / pulsar`.
  Името за менюто — в `S.LEVEL_INFO` (`js/sim/progress.js`). Фонът — `BG.defs.<bg>` (`parts`: на колко ивици се
  обновява; `scale`: дял от разделителната способност — за бързо движещи се фонове `parts: 1`).
- **музика**: запис в `TR` в `js/audio.js` (акорди `A`/`B`, бас, арпеджио, барабани, мелодия).
- Нов файл → ред `<script src>` в `index.html` на правилното място (логиката преди рисуването).

## Проверки
```
node dev/sim.js              # автопилотът минава всяко ниво × трудност; 0 изключения; отпечатък, еднакъв при две пускания
node dev/sim.js 5 1          # само ниво 5, Нормално
node dev/sim.js --human      # „като човек“ (бавна реакция, по-слабо избягване), 6 семена — кривата на трудностите
python3 dev/check.py         # 0 пътища навън, 0 Math.random в логиката, manifest и икони на място
```
Снимки без ръце (Chrome в headless режим или в браузъра):
`index.html#t=900` (фонът на менюто), `#t=7000&hud&lvl=2&seed=5` (игра с автопилот), `#t=400&scr=hangar` (екран).
В конзолата: `__space` (`adv(n)`, `freeze`, `zoom={x,y,k}`, `start()`), клавиш `` ` `` — брояч на кадрите и стъпалото на качеството.

## Инструменти
- `python3 dev/fonts.py` — тегли шрифтовете от Google Fonts и ги вгражда (иска мрежа).
- `python3 dev/icon.py` — рисува иконите за начален екран (иска numpy).

## Управление
Стрелки/WASD — движение · Space/Z — стрелба · X/Shift — вземи от скалата · C — резонансен удар · Esc/P — пауза ·
F — цял екран · M — музика. На телефон: корабът следва пръста с отместване, стрелбата е сама, бутоните „Вземи“ и „Удар“ са вдясно.
